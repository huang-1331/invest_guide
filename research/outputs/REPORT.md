## 실행 차단 원인

1. 실행 환경에 `OPENDART_API_KEY`가 없습니다. 이전 키를 탐색·재사용하지 않았습니다.
2. 무키 OpenDART 일괄다운로드 색인은 접근되지만 실제 2025년 4분기 BS ZIP 요청은 HTTP 200의 오류 HTML(975 bytes)을 반환했습니다. 세션·Referer를 유지한 재요청도 동일했습니다.
3. KRX 직접 요청은 초기에 403, 재시도는 HTML 접근 성공이었으나 구조화된 과거 전체 상장 이력 확보로 이어지지 않았습니다. KIND의 공식 목록·이력은 별도로 수집했습니다.
4. 현재 공개된 정정 일괄자료는 과거 공시 당시 값이라는 보증이 없습니다. 공시일·정정본 검증 없이 학습자료로 우회하지 않았습니다.
5. 2025년까지 재무자료만 확보하면 2024~2025년 예측의 24개월 무사건 라벨은 상당수 확정할 수 없습니다. 충분한 미래 추적 또는 사전 합의한 더 이른 테스트 기간이 필요합니다.
