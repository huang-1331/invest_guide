# 연구 방법과 현재 한계

## 사건과 표본

- 주 분석: 한국 비금융업, 12월 결산, **OFS 별도 자본총계 ≤ 0**의 최초 관측 회계기간 말. 자본총계 0을 포함합니다. 법적 상장폐지 사유 판정과는 다릅니다.
- CFS 연결은 별도 설정의 민감도 연구입니다. OFS와 같은 시계열에 섞거나 자동 대체하지 않습니다. CFS의 비지배지분 포함 자본총계는 OFS와 다른 정의이며 지배주주지분 분석도 별도 필요합니다.
- 최초 관측부터 자본총계 ≤0 또는 최초 자본 결측인 기업은 좌측 검열로 주 사건 분석에서 제외. 2015년 시작 자료만으로 기업 생애 최초 사건을 단정할 수 없으므로 “관찰창 내 최초 관측”으로 표현합니다.
- 사건일 = 비양수 자기자본 회계기간 말, 사건 공개일 = 그 재무제표의 공시일. 사건일 이후·공개일 이전의 예측도 제외합니다. 사건은 분기 관측이므로 실제 발생시점은 구간 검열되나 구현은 분기말로 근사합니다.
- 자본총계 >0이면서 자본금 미만은 부분잠식, 자본총계 ≥자본금은 비잠식으로 기술 분류 가능합니다. 회복은 과거 비양수 후 양수로 전환입니다. 회복 후 재발은 최초 사건 예측의 새 정상 표본으로 재투입하지 않습니다. 상태 분류 CSV 생성 기능은 구현했으며, 실제 파일은 검증된 재무자료 확보 후 생성됩니다.
- 재상장·분할·합병·결산월 변경·중복 종목은 수동 검토 전 제외합니다. 보통주 기업 단위; 여러 주식종류를 기업 여러 개로 세지 않습니다.
- 상장폐지 라벨은 KRX/KIND 폐지일로 별도 생성합니다. 이전상장·합병 등의 사유를 완전자본잠식으로 바꾸지 않습니다. 부도/상폐에 대한 별도 모형 적합은 현재 범위 밖입니다.

## 공시 시점과 정정

`filed_at <= anchor`인 자료만 사용하고 각 예측일에 해당 분기의 최신 공개본을 다시 선택합니다. 최신 정정값을 최초 공시일로 소급하지 않습니다. OpenDART API가 반환한 정확한 접수번호와 공시검색의 날짜가 매칭되는 경우만 입력합니다. API가 현재 정정본만 제공하면 이전 시점은 복원하지 않으며 오래된 분기 당시 표본이 소실될 수 있습니다. 수정 전 원문 확보 없이는 PIT 복원이 완전하지 않습니다.

예측 라벨은 anchor 이후 12·24개월 **이내 사건**입니다. “정확히 사건 12개월 전 수치”와 다릅니다. 계정 기간과 의사결정일 간 시차를 유지합니다. 무사건 라벨은 관찰기간이 horizon을 채우고 연속 분기 자본 자료가 있어야 합니다. 없으면 NaN. 라벨의 공개 확인일이 다음 평가 구간 시작보다 앞선 학습·검증 행만 사용합니다. 분기 누락은 연속 추적 끝에서 검열합니다. 상폐 시점에도 사건 미확인이면 검열하며, 이는 정보성 검열 가능성이 있습니다.

## 변수

모든 비율은 무단위이며 원화 금액으로 통일합니다. 양수 분모가 아닌 경우 결측. 자본잠식률은 `(자본금-자본총계)/자본금`이며 100을 곱하면 %입니다. 음수 잠식률(자본 여유)은 원값 보존합니다.

| 변수 | 정의 |
|---|---|
| 부채/자산 | 총부채/기말 총자산 |
| ROA | 최근 4개 독립분기 순이익 합/기말 총자산 |
| 유동비율 | 유동자산/유동부채 |
| OCF/자산 | 최근 4개 독립분기 영업현금흐름 합/기말 총자산 |
| 영업이익률 | 최근 4분기 영업이익 합/동기간 매출 합 |
| 연속 적자 분기 | 독립분기 순이익이 음수인 최근 연속 길이; 결측에서 중단 |
| 4·8분기 변화 | 비율의 현재-과거 및 `(현재-과거)/abs(과거)`; 과거=0이면 변화율 결측 |
| 자기자본 증가율 | 전년 동분기 대비 `(현재-과거)/abs(과거)` |
| ROE | 최근 4분기 순이익/기말 양수 자기자본 |
| Log 유동부채비율 | `ln(유동부채/양수 자기자본)`; 2013 원문 분모 확인 전 근사 사양 |

손익·현금흐름 입력은 연초 이후 누적(YTD)입니다. 당분기는 누적 차분으로 구하고 1분기는 원값 사용. 4분기는 연간-3분기 누적. 연속 분기를 보장하기 위해 누락 분기를 재색인합니다. 연간 금액을 독립 분기처럼 섞지 않습니다. ROA·ROE에 평균자산·평균자본을 쓰는 정의와 다르며 이는 명시적 사양 선택입니다.

`Z″ = 6.56 WC/TA + 3.26 RE/TA + 6.72 EBIT/TA + 1.05 BVE/TL`.

Altman(2002)의 장부가치 기반 Z″, +3.25를 더한 EM 신용등급 변환은 사용하지 않습니다. WC=유동자산-유동부채, RE=이익잉여금, BVE=장부자본. EBIT은 실제 검증된 계정을 요구합니다. `ifrs-full_ProfitLossFromOperatingActivities` 매핑은 기업별 EBIT 의미를 원문 확인해야 하며 일반 영업이익을 자동 대입하지 않습니다. 적합한 EBIT 계정이 없으면 결측 처리하여 비교가 차단될 수 있습니다. 비금융업 적용의 외적 타당성은 별도 검증 대상입니다.

## 2013년 연구와 비교

주정아(2013)의 공개 초록 기준 로지스틱 접근을 구현했습니다. 원문 회귀계수, 변수 산식·단위, 원 표본 DB, 매칭과정이 확보되지 않았으므로 **정확 재현은 미완료**입니다. 12개월은 Log 유동부채비율·ROE, 24개월은 자기자본증가율·Log 유동비율을 사용합니다. 현대자료에서 새로 추정하는 계수이며 초록의 유의변수만 선택한 근사입니다. 부분잠식까지 포함할 수 있는 원연구의 목표와 본 연구 완전자본잠식 목표도 다릅니다.

개선 Logistic은 재무 수준+변화량을 사용합니다. 이를 기존 Logistic 및 Altman과 동일 테스트 행에서 비교합니다. 과거 매칭표본의 정확도를 현대 시장 표본의 정확도와 직접 비교하지 않습니다.

## 검증

기업 hash(seed와 별개로 SHA256 고정)로 60/20/20%를 분리하고 시간도 분리합니다. 기업을 셋 사이에서 재사용하지 않습니다. 24개월 라벨 확인을 위한 공백을 두고 train 종료 2018, validation 2021, test 2024~2025를 초기 설정으로 사용합니다. 이는 시간순 분리와 신규 기업 일반화를 동시에 평가하여 표본효율이 낮습니다. 고정 해시가 사건 수를 보장하지 않습니다. 테스트·검증은 사건 균형화하지 않지만 모집단 누락·무관측·검열로 자연 시장 분포가 보장되지는 않습니다. 모집단 완전성 검증이 필수이며 기준모형 결측으로 테스트가 줄면 비교를 차단합니다.

결측 대치·표준화는 train에서만 학습합니다. 원 Altman·근사 Logistic 필수 변수의 결측은 공통 비교에서 제거하며 전후 표본 수를 기록합니다. XGBoost/개선 Logistic은 train 중앙값+결측지시자를 사용합니다. DTW도 train의 변환만 사용합니다. 검증에서 F1 최대 임계값을 고정하고 테스트에서 변경하지 않습니다. Platt 보정도 검증에서만 적합합니다. 검증셋에서 임계값과 보정을 함께 선택하므로 검증 수치 자체는 일반화 성능으로 보고하지 않습니다.

클래스가 한 개이거나 표본이 없으면 모형 비교를 중단합니다. 동일 기업의 여러 예측행 상관을 반영하도록 기업 단위 부트스트랩을 1,000회 수행합니다. CI는 고정된 모델의 테스트 샘플 불확실성이며 재학습·하이퍼파라미터 탐색 불확실성은 포함하지 않습니다. PR-AUC는 Average Precision 정의입니다. FPR=FP/(TN+FP). Cox는 학습 종료에서 행정 검열하고 고정 landmark 방식으로 적합합니다. 시간의존 AUC는 IPCW 지원범위 밖이면 평가 불가 사유를 저장합니다. Cox 기간은 월×365.25/12 근사이고 분류 라벨은 달력 월 기준이라 경계일 차이가 남습니다.

미완료: 생존지표 CI, IPCW Brier, PH 가정 진단, 구간검열 모형, 기업/업종별 안정성, 사전 등록, 하이퍼파라미터 탐색, 20건 이상 실제 사건 검증. 현재 결과를 실증 연구 완료나 투자 위험 확률로 사용하지 않습니다.
