## 2. 공식 및 예시 계산

| 지표 | 적용 산식 | 예시 계산 | 판정 |
|---|---|---|---|
| PER | 주가 / EPS | 10,000 / 1,000 = 10배 | 일치 |
| PBR | 주가 / BPS | 10,000 / 5,000 = 2배 | 일치 |
| 부채비율 | 부채총계 / 자본총계 ×100 | 200억 / 100억 ×100 = 200% | 일치 |
| 시가총액 | 주가 × 상장주식 수 | 10,000원 × 100만 주 = 100억 원 | 일치 |
| EPS(기본 개념) | 보통주 귀속 순이익 / 가중평균 유통보통주식 수 | 10억 원 / 100만 주 = 1,000원 | 일치 |
| ROE(간략식) | 당기순이익 / 평균 자기자본 ×100 | 10억 원 / 100억 원 ×100 = 10% | 일치 |
| 영업이익 예시 | 매출액 - 영업 관련 원가·비용 | 100억 - 85억 = 15억 원 | 일치 |

- `calculatePer`: EPS ≤ 0 또는 비정상 숫자에 대해 `null` 반환하도록 정의되어 있음. **실행 테스트가 아니라 코드 검토 결과**.
- ROE: 지배주주지분/연결 기준 등의 세부 차이에 따라 정식 산식은 달라질 수 있으므로 간략식으로만 설명.
- EPS: 실제 공시에서는 우선주, 희석효과 및 가중평균 주식 수 등 확인 필요.
- PER 또는 PBR이 낮다고 저평가로 확정하지 않도록 설명되어 있음.

## 3. 퀴즈 정답 검수

| ID | 연결 수업 | 정답 인덱스(0부터) | 정답 요지 | 판정 |
|---|---|---|---|---|
| Q01 | 01 | 0 | 주식은 기업 소유권 일부 | 일치 |
| Q02 | 02 | 1 | 이익이 나도 현금흐름 부족 가능 | 일치 |
| Q03 | 03 | 2 | PER = 10배 | 일치 |
| Q04 | 04 | 3 | 분산투자는 특정 기업 집중 위험을 줄이는 데 도움 | 일치 |

- 수업 `quizId` ↔ 퀴즈 `id`, 퀴즈 `lessonId` ↔ 수업 `n` 관계 확인.
- 보기·정답·해설 간 명백한 모순은 발견하지 못함.

## 4. 교육 문구 검수

- 수업 01: 소유권, 배당/원금 비보장 표현 적절.
- 수업 02: 회계상 이익과 현금흐름 구분 적절.
- 수업 03: PER·PBR 해석과 EPS 0 이하 예외 설명 적절.
- 수업 04: 분산투자의 한계 및 자료 미연결 시 '평가 불가' 표현 적절.
- 용어 10개 정의와 예시는 초보자 교육 수준에서 대체로 타당.
- `dataMeta`에 demo 모드, 가상 가격·변동률·차트, 실제 회사 식별정보 구분 명시.
- **주의:** 문헌·공시·법령 기준의 외부 교차 검증은 이번 정적 검토에 포함되지 않음.

## 5. A에게 전달할 통합 확인 사항

| 우선순위 | 위치 | 이슈 | 요청 |
|---|---|---|---|
| 필수 | `app.js` `lesson()` | `lessonText`와 2지선다 `questions` 하드코딩 | `lessons[].content`, `quizzes[]` 사용; 4지선다/해설 연결 |
| 필수 | `app.js` 학습 | 수업·퀴즈 완료 기록이 저장되지 않음 | `localStorage` 기반 완료 상태 저장/복원/초기화 |
| 필수 | `app.js` `term()` | 설명용 `terms[].example` 화면에 미반영 | 용어 예시 필드 표시 검토 |
| 필수 | `app.js` `term()` | PER 슬라이더의 EPS=1000이 코드에 고정 | `perPractice` 및 `calculatePer` 참조 |
| 참고 | `app.js` 기간별 차트 | 기간 버튼이 실제 날짜 자료가 아니라 점 배열을 변형 | 모두 가상 시연 차트임을 유지; 실제 기간 데이터처럼 표현하지 않음 |
| 참고 | 기업 데이터 | 실제 회사명·코드와 가상 가격 혼합 | 모든 카드·상세에 예시 표시 유지 |

## 6. 검수 한계 및 출시 판정

- B02 **데이터 구조·내용·산식 검토 완료**.
- 실제 브라우저 조작, 모바일, 키보드, 접근성, 배포 URL 기능 테스트는 **미실시**.
- A의 화면 연동 전에는 '수업·퀴즈 연결 완료'로 판정하지 않음.
- 투자 위험 확률/등급은 본 MVP 범위 밖이며, 자료 미연결 시 '평가 불가' 유지.
- 배포 승인 조건: A가 화면 연동을 완료하고 B04 시나리오를 통과해야 함.
