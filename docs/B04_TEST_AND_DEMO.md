## 2. A에게 전달할 차단 오류

1. **P0** `app.js`의 `lesson()`에서 `lessons[].content`와 `quizzes[]`를 사용하고, 선택지 4개·정답·오답 해설 출력.
2. **P0** 학습/퀴즈 완료 기록을 브라우저에 저장하고 새로고침 후 복원하며 초기화 버튼 제공.
3. **P1** `terms[].example`을 상세 모달에 표시하고 `perPractice`·`calculatePer`로 PER 실습 연결.
4. **P1** 해시 직접 진입·모달 닫기·빈 검색을 모바일 및 키보드로 확인.
5. **P1** 배포 URL에서 핵심 경로 완주 및 협업자 접근 확인.

B는 A 소유의 `app.js`를 임의로 수정하지 않음.

## 3. 브라우저에서 수행할 테스트 순서

- 사이트 홈 접속 → 회사명 '삼성' 검색 → 카드·상세·차트·예시 라벨 확인 → 모달 ESC 닫기.
- 검색어 '존재하지않는기업' → 빈 결과 메시지 확인.
- `#company-005930` 주소 직접 열기/새로고침 → 상세 모달 유지 확인.
- 용어 사전 10개 순회 → 예시 설명 확인 → PER 10,000/1,000=10 확인.
- `#learning` → 4개 수업 진입 → 각 4지선다 정답/오답과 해설 확인.
- 수업 완료/퀴즈 결과 저장 → 페이지 새로고침 → 학습 기록 유지 → 초기화 확인.
- 관심기업 추가 → 새로고침 → 관심기업 페이지 → 해제 확인.
- 모바일 375px, 데스크톱 1280px, Tab/Enter/Escape, 마우스 없이 조작 가능 여부 검증.
- 로그인 없이 동료 브라우저에서 공개 URL 접속 및 동작 확인.
