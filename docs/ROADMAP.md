# 주식의 이해 — 3일 초고속 MVP·2인 분할

- 일정: 착수일부터 3일. 1인 하루 6~8시간, 총 36~48인시 가정.
- 목표: 기업 검색 → 상세 → 용어 해설 → 퀴즈가 끊기지 않는 배포본.
- 전략: 기존 UI 재사용·범위 고정·예시 데이터 우선·실제 데이터는 최소 연결.
- 완료 수준: 협업·사용성 시연 가능한 MVP. 정식 금융정보 서비스 아님.
- A/B는 역할 표기. 실제 담당자·착수일 미정.

## 1. 범위 고정

| 반드시 완료 | 여유가 있을 때 | 이번에 제외 |
|---|---|---|
| 예시 기업 4개 검색·상세·차트 | 실제 기업 1개의 일별 가격 | 로그인·회원가입 |
| 용어 10개·수업 4개·퀴즈 4개 | 실제 공시 목록·원문 연결 | 뉴스 API·AI 상담 |
| PER 실습 1개 | 기업 비교 화면 | ML 위험 점수·위험 등급 산출 |
| 관심기업·학습 기록 브라우저 저장 | 교육 콘텐츠 추가 | 실시간 시세·서버 사용자 저장 |
| 출처·예시·미연결·평가 불가 표시 | 추가 차트 기간 | 정기 수집·알림·자동화 |
| 반응형·직접 링크·배포·공동 접근 | — | 전면 리팩터링·프레임워크 이전 |

- 실제 가격·공시 연동은 출시 필수 조건에서 제외.
- 실제 자료 연결 시 공급원 이용조건·출처·기간·기준일 확인 필수.
- 자료 미연결은 예시 또는 평가 불가. 실제 분석처럼 포장하지 않음.
- 교육 설명·공식·퀴즈 정답은 최소 상호 검토.

## 2. 2인 역할

| 담당 | 소유 영역 | 수정 파일·산출물 |
|---|---|---|
| A: 화면·사용 경험 | 화면 연결·차트·저장·반응형·배포 | dist/index.html, dist/styles.css, dist/app.js |
| B: 데이터·교육 | 예시 데이터·용어 10개·수업/퀴즈·API 경계·계산 검수 | dist/data.js, docs/API_CONTRACT.md, docs/CONTENT_REVIEW.md |
| 공동 | 범위·통합·사용 시나리오·출시 판정 | README.md, 출시 체크리스트 |

- app.js는 A만 수정. B는 필요한 연결 변경을 짧은 목록으로 전달.
- B의 데이터 구조 변경은 A와 먼저 합의. 첫날 오전 이후 필드 변경 최소화.
- 실제 데이터 연결은 B의 선택 작업. 핵심 교육·예시 데이터 완성 후 진행.
- 서버·DB 신규 구축은 하지 않음. 기존 repository 경계를 추후 API 어댑터로 교체 가능하게 유지.
- API 키가 필요한 연동은 서버 측 경로가 준비된 경우에만 진행. 키를 브라우저 코드에 넣지 않음.

## 3. 3일 실행표

| 시점 | A 작업 | B 작업 | 통합 산출물 |
|---|---|---|---|
| 1일 오전 | 공동 실행·현재 화면 점검·저장 흐름 설계 | 데이터 필드·콘텐츠 목록·샘플 응답 확정 | 두 사람 실행 성공·작업 경계 확정 |
| 1일 오후 | 검색→상세→학습→퀴즈 연결·직접 링크 점검 | 기업 4개·용어 10개·수업 4개·퀴즈 4개 준비 | 예시 데이터로 핵심 흐름 1회 완주 |
| 2일 오전 | 학습 기록 저장·복원·초기화, 빈 결과 처리 | PER·퀴즈 정답·교육 문구 검토, API 계약 문서 | 필수 기능 전부 연결 |
| 2일 오후 | 모바일·모달·키보드·예시 표시 수정 | 실제 데이터 1개 연결 가능성 확인, 미연결 상태 검수 | 배포 후보·선택 연동 종료 판단 |
| 3일 오전 | 치명적 오류 수정·배포 환경 점검 | 수치·문구·출처·결측·저장 시나리오 검증 | 수정 목록 소진·최종 후보 |
| 3일 오후 | 최종 배포·협업자 접근 확인 | 시연 순서·운영 한계·후속 작업 문서 | 5분 시연·인수인계 완료 |

## 4. 강제 마감선

- 1일 오전 종료: 공동 코드 접근 해결. 별도 저장소 생성이 막히면 버전이 표시된 ZIP으로 인계하고 파일 소유권 유지.
- 1일 종료: 예시 데이터로 전체 경로 동작. 미완료 시 화면 장식·추가 기능 중단.
- 2일 정오: 필수 기능 고정. 이후 새 기능 추가 금지. 선택 연동은 기존 UI를 바꾸지 않는 연결만 허용.
- 2일 16시: 실제 데이터 연동 실패·공급 조건 미확정이면 즉시 예시 모드로 확정. 재시도로 일정 소모 금지.
- 3일 정오: 배포 후보 고정. 이후 차단 오류만 수정.
- 3일 종료: 배포·접근 확인·시연 완료. 해결되지 않은 항목은 제한사항과 후속 목록에 기록.

- 공유 프로젝트는 결정·검토 기록용. 로컬 코드·Sites 접근권한은 자동 공유되지 않으므로 별도 확인.

## 7. 시연 순서·후속

- 5분 시연: 기업 검색 → 상세 차트 → PER 해설·실습 → 수업·퀴즈 → 관심기업·기록 복원.
- 데이터 연동이 없으면 처음부터 예시 모드라고 설명.
- 3일 이후 우선순위: 실제 기업 1개 연결 → 일별 가격·공시 → 재무 → 대상 확대 → 규칙 검수 → 로그인·서버 저장.
- 정식 서비스 전 별도 검토: 공급원 이용조건·교육 검수·갱신 운영·위험 기준·개인정보 처리·사용자 간 접근 통제.
